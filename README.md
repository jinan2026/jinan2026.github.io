# 锦安数字科技有限公司

具身智能真实场景数据采集服务｜江苏·无锡

公司官网源文件。首页为 `index.html`，样式为 `styles.css`，交互为 `app.js`；公开联系信息通过 `site-config.js` 管理。

计划访问地址：https://jinan2026.github.io/

## 部署

在仓库 Settings → Pages 中选择 Deploy from a branch，使用 main 分支的根目录。网站是纯静态页面，无需安装依赖。

## 联系方式

官网联系区展示公司授权公开的企业微信二维码，可点击放大。项目需求清单仅在浏览器中生成，由访问者自行发送。
